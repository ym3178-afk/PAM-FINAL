# Behind the Route — 12-chapter script-aligned website

This version is synchronized with the final 1–12 chapter presentation script.

## Narrative structure

1. Title — personal experience and motivation
2. Research questions — omission, production, revelation, responsible evidence
3. Keywords — object, entry point, hidden system, human experience, method
4. Intersecting fields — movement, power, representation
5. Historical lineage — local supply to algorithmic dispatch, plus “partial knowing”
6. Community of practice — critical practices, labor/public accountability, platform builders
7. Methods — one fixed Columbia-area delivery case and a transparent evidence protocol
8. Computational experiment — One Journey, Multiple Route Logics
9. Visual representation — layer, compare, disclose
10. Rhetorical argument — The route is not found. It is produced.
11. Potential capstone — interactive route simulator + situated route archive
12. Challenges — data, validation, rider participation, and interface clarity
