# Behind the Route — Front six chapters revised

The first six chapters now follow one explicit narrative:

1. Experience — Why do I care?
2. Research questions — What do I want to know?
3. Keywords — What is the project about?
4. Intersecting fields — How can I study it?
5. Historical lineage — How did this system emerge?

The visual structures and interactions are retained, while headings, explanatory text, disciplinary groupings, historical argument, and community positioning are rewritten to make the connections between chapters clear.
